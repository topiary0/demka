# Отчет о проверке работы системы

> Текстовый отчет добавлен вместо DOCX, так как бинарные файлы в репозитории не поддерживаются.

## Проверяемые сценарии

1. Запуск приложения открывает окно авторизации.
2. Вход по логину и паролю проверяет данные из таблицы `users`.
3. Гостевой вход открывает список товаров без административных действий.
4. Для менеджера и администратора доступны поиск, сортировка и фильтрация товаров.
5. Для администратора доступны добавление, редактирование и удаление товаров.
6. Удаление товара блокируется, если товар есть в заказах.
7. Для менеджера и администратора доступен список заказов.
8. Для администратора доступны добавление, редактирование и удаление заказов.
9. После изменений списки товаров и заказов обновляются.
10. Кнопка выхода очищает сессию и возвращает пользователя на форму входа.
