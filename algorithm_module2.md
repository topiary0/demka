# Алгоритм разработки приложения (модуль №2)

> Исходник алгоритма хранится в текстовом формате, потому что бинарные файлы в репозитории не поддерживаются. При необходимости этот файл можно экспортировать в PDF средствами редактора Markdown.

```mermaid
flowchart TD
    A([Старт приложения]) --> B[Открыть форму авторизации]
    B --> C{Пользователь выбрал гостевой вход?}
    C -- Да --> D[Установить роль Гость]
    C -- Нет --> E[Проверить логин и пароль в таблице users]
    E --> F{Данные верны?}
    F -- Нет --> G[Показать сообщение об ошибке]
    G --> B
    F -- Да --> H[Сохранить ФИО и роль пользователя в Session]
    D --> I[Открыть список товаров]
    H --> I
    I --> J[Загрузить товары из БД с категорией, производителем и поставщиком]
    J --> K[Применить поиск, фильтр по поставщику и сортировку]
    K --> L[Вывести товары и подсветить строки по скидке/остатку]
    L --> M{Роль Администратор?}
    M -- Да --> N[Доступны добавление, редактирование и удаление товаров]
    M -- Нет --> O[Только просмотр или функции роли]
    N --> P{Открыт модуль заказов?}
    O --> P
    P -- Да --> Q[Показать список заказов]
    Q --> R{Роль Администратор?}
    R -- Да --> S[Доступны добавление, редактирование и удаление заказов]
    R -- Нет --> T[Только просмотр заказов]
    S --> U[Обновить список после изменений]
    T --> U
    P -- Нет --> V{Выход?}
    U --> V
    V -- Нет --> I
    V -- Да --> W[Очистить Session и вернуться на форму входа]
    W --> X([Конец])
```
